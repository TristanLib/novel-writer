# Chapter production

Use this reference for new chapters, continuations, rewrites, and expansions.

## Contents

- Context and cross-volume synchronization
- Durable-term reverse search
- Chapter card and drafting rules
- Acceptance sequence
- Human-texture pass
- Handoff

## Context sync

Read the smallest evidence set that prevents continuity mistakes:

- project instructions and collaboration rules;
- premise, chapter scale, file layout, and current progress;
- current continuity snapshot and target chapter card;
- relevant style guide;
- domain or capability rules when professional, dangerous, legal, medical,
  financial, technical, institutional, or special-ability material appears;
- mystery or evidence ledger when clues, hidden identities, deaths, objects,
  documents, organizations, or major reveals appear;
- character or series files only when relationships, motives, or world rules
  remain unclear.

If expected files do not exist, discover the closest equivalents and state the
assumption. Preserve the project's established layout rather than forcing a
template.

## Cross-volume context

For volume two or later:

1. Read the immediately preceding volume's detailed outline or chapter map as
   an index.
2. Read the current-volume continuity snapshot, current progress, and target
   card.
3. Use the prior outline to locate prose for exact scenes, dialogue, emotional
   turns, character knowledge, relationship changes, object custody, important
   text wording, propagation, or disputed causality.
4. Read prior prose whenever summaries conflict or those chapters enter the
   reader-forward review window.

Do not load every earlier chapter by default. Keep loading priority separate
from fact authority: completed prose still wins.

## Reverse-search durable terms

Before writing mystery-bearing or continuity-sensitive material, list exact
names, titles, objects, documents, medicines, locations, institutional terms,
and hook phrases plus obvious variants.

Search manuscript, docs, and progress files:

```bash
rg -n "exact term|variant term" manuscripts docs progress-file.md
```

Use hits to confirm first appearance, wording, source, custody, knowers,
current interpretation, future recovery window, and contradictions. Inspect
the previous three endings before accepting a new hook.

## Build the chapter card

Use the detailed template in `outline-templates.md`. At minimum settle:

- immediate ordinary-reader question;
- central action and meaningful choice;
- same-chapter promise and bounded payoff;
- visible state change;
- human consequence;
- capability and evidence boundaries;
- specific next drive;
- hook type and new information;
- what becomes missing if the chapter is removed.

Advance at least one of new information, conflict, choice, or cost. Tie
procedure and puzzle movement back to people, identity, resources,
institutional pressure, theme, or consequence.

## Draft or revise

- Write one independently stored chapter using the project's naming and length
  rules.
- Preserve existing function points during a rewrite unless the user requests
  a new contract.
- Add length only through action conditions, causality, scene pressure, choice,
  evidence, cost, relationship movement, or result.
- Remove repeated explanation, but do not compress a scene into an outline-like
  sequence of arrivals, handoffs, reversals, and exits.
- Give antagonists and allies independent interests.
- Let a win land before making its cost concrete.

## Acceptance sequence

Run these checks in order:

1. prose-only retention audit;
2. reader-forward linked-chapter continuity;
3. formal severity audit;
4. human-texture and prose polish;
5. full retention and continuity sequence again on the final text;
6. durable state synchronization.

If any check changes prose, facts, relationships, object state, evidence order,
important text propagation, chapter payoff, pacing load, or the ending hook,
restart from the retention audit. Accept the chapter only when all gates pass
consecutively on the same exact version.

## Human-texture pass

Before final polish:

- remove over-neat explanation, repeated sentence frames, slogan-like theme
  statements, and dialogue where every speaker sounds like the outline;
- replace generic summary with concrete objects, bodily reaction, fatigue,
  impatience, partial knowledge, interruption, local idiom, awkward silence,
  status pressure, and practical decisions;
- reduce repeated proof language such as `not X but Y`, `this proves`, `only
  enough to show`, or `cannot determine yet`;
- avoid ending every chapter on a new letter, name, mark, ledger, threat, or
  unknown observer.

Do not create fake messiness, random dialect, ornamental filler, or unrelated
banter.

## Handoff

Report:

- chapter or planning files changed;
- exact final text version;
- retention score and direct continuation verdict;
- linked chapters read and formal audit result;
- applicable rolling-window result;
- state files updated;
- unresolved risks and the next concrete bridge.

Do not claim market validation without comparable cold-reader or live-platform
evidence.
